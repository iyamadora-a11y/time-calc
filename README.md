# 시간 & 날짜 계산기 (PWA)

PC·스마트폰 겸용 웹앱입니다. 인터넷에 한 번 올려두면 **홈 화면에 설치**되고, 이후에는 **오프라인에서도** 동작합니다.

## 탭 구성

- **시간 계산** — 기준 시각 ± 시간/분. 하루를 넘기면 날짜까지 함께 표시
- **날짜 계산** — 기준 날짜 ± 년/개월/주/일 (혼합 입력)
- **차이 계산** — 두 시각 사이의 총 시간, 두 날짜 사이의 총 기간(일·주·개월·년 중 선택)

화면 맨 아래 **탭 순서 변경**에서 ↑↓로 탭 배치를 바꿀 수 있고, 선택은 기기에 저장됩니다.

## 입력 편의 기능

- **숫자 키패드** — `최근 계산` 바로 위에 1~9 · 0 · `칸이동` · 지우기(⌫) 키패드가 있습니다. 커서가 놓인 칸(테두리가 강조된 칸)에 숫자가 들어가고, 칸이 다 차면 다음 칸으로 자동으로 넘어갑니다. 빈 칸에서 ⌫ 를 누르면 앞 칸으로 돌아갑니다. `칸이동` 은 그 탭의 다음 칸으로 커서를 옮기고, 마지막 칸에서는 첫 칸으로 돌아옵니다.
  - 키패드를 쓰기 때문에 입력칸을 눌러도 **기기 기본 키보드는 올라오지 않습니다** (`inputmode="none"`). 기본 키보드를 다시 쓰려면 `index.html`에서 `inputmode="none"` 을 `inputmode="numeric"` 으로 바꾸면 됩니다.
  - PC에서는 물리 키보드 입력도 그대로 됩니다.

- **자동 다음 칸 이동** — 시간 4자리(`2230`) 또는 날짜 8자리(`20260131`)를 다 입력하면 커서가 저절로 다음 칸으로 넘어갑니다. 칸을 다시 탭할 필요가 없고 키보드도 내려가지 않습니다.
- **자동 계산** — `계산` 버튼을 누르지 않아도 입력이 완성되는 순간 결과가 갱신됩니다. `+ / −` 를 바꾸거나 달력에서 날짜를 고를 때도 바로 다시 계산합니다.
  - 입력이 덜 됐거나 형식이 틀렸을 때는 결과만 비워두고 **오류 문구는 띄우지 않습니다**. 안내가 필요하면 `계산` 버튼을 누르세요.
  - **최근 계산 기록**은 `계산` 버튼을 눌렀을 때만 쌓입니다 (타이핑 중에는 쌓이지 않음).
- **마지막 선택 기억** — `+ / −` 와 차이 계산의 `결과 단위`는 마지막에 고른 값이 기기에 저장되어 다음에 열 때 그대로 표시됩니다. `전체 초기화`는 입력과 결과만 비우고 이 선택은 건드리지 않습니다.
- **기준값 버튼** — 결과 옆 `기준값` 을 누르면 결과가 기준 시간(기준 날짜) 칸으로 옮겨지고 바로 다시 계산됩니다. 같은 간격을 이어서 더해 나갈 때 한 번씩만 누르면 됩니다.

## 폴더 구성

```
index.html              앱 본체 (HTML·CSS·JS 모두 포함)
manifest.webmanifest    앱 이름·아이콘·전체화면 설정
sw.js                   오프라인 캐시(서비스 워커)
icons/                  앱 아이콘 (192 / 512 / iOS / 파비콘)
```

외부 라이브러리·폰트를 전혀 사용하지 않으므로 이 폴더만 있으면 완전하게 동작합니다.

## 올리는 방법 (셋 중 하나)

### 1. Netlify Drop — 가장 빠름 (약 1분, 로그인 불필요)

1. https://app.netlify.com/drop 접속
2. 이 폴더(압축 해제된 상태)를 통째로 드래그 앤 드롭
3. 바로 `https://○○○.netlify.app` 주소가 생성됩니다

### 2. GitHub Pages — 사내에서 계속 쓸 때

1. 새 저장소 생성 → 이 폴더의 파일을 전부 업로드
2. Settings → Pages → Source를 `main` 브랜치 / `/ (root)`로 지정
3. 몇 분 뒤 `https://<계정>.github.io/<저장소>/` 주소로 접속

### 3. 사내 웹서버 / 공유 폴더

`index.html`이 있는 폴더 그대로 웹서버 경로에 복사하면 됩니다.
**HTTPS(또는 localhost)여야** 설치와 오프라인 기능이 활성화됩니다. (HTTP로 열면 계산기는 정상 동작하지만 설치·오프라인 기능은 비활성)

## iPhone에서 앱으로 쓰기 — GitHub Pages 기준 (개인용)

### PC에서 한 번만 설정 (약 10분)

1. https://github.com 가입 (무료)
2. 우측 상단 `+` → **New repository** → 이름 `time-calc` → **Public** 선택 → Create repository
   - 무료 계정은 Public 저장소에서만 Pages가 동작합니다. 주소를 아는 사람은 열 수 있지만, 검색 노출을 막는 `robots.txt`가 포함되어 있습니다.
3. **Add file → Upload files** → 이 폴더 **안의 내용물**(`index.html`, `manifest.webmanifest`, `sw.js`, `robots.txt`, `icons` 폴더)을 드래그 → **Commit changes**
   - 폴더째가 아니라 안의 파일들을 올려야 주소가 깔끔합니다.
4. **Settings** 탭 → 좌측 **Pages** → Build and deployment
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)` → **Save**
5. 1~10분 뒤 `https://<아이디>.github.io/time-calc/` 로 접속

### iPhone에서 설치

6. **Safari로** 위 주소를 엽니다 (Chrome이 아니라 Safari여야 설치됩니다)
7. 하단 **공유 버튼** → `홈 화면에 추가` → `추가`
8. 홈 화면 아이콘으로 실행하면 주소창 없는 전체화면으로 열립니다
9. 한 번 실행한 뒤에는 비행기 모드에서도 동작합니다

### 수정할 때

`index.html`을 고쳐 다시 업로드하고, `sw.js`의 `tdc-v1` → `tdc-v2`로 버전을 올립니다. 그래야 설치된 아이콘에서도 새 버전이 반영됩니다.

## 설치 방법 (일반)

- **iPhone / iPad (Safari)**: 주소 접속 → 하단 공유 버튼 → `홈 화면에 추가`
- **Android (Chrome)**: 주소 접속 → 화면 상단의 `설치` 버튼, 또는 ⋮ 메뉴 → `앱 설치`
- **PC (Chrome / Edge)**: 주소창 오른쪽 설치 아이콘 클릭

설치하면 주소창 없는 전체화면으로 실행되고, 두 번째 실행부터는 인터넷 없이도 열립니다.

## 파일을 직접 열어서 쓰는 경우

`index.html`을 더블클릭해도 계산 기능은 모두 동작합니다. 다만 `file://`로 열면 브라우저 정책상 설치·오프라인 캐시는 동작하지 않습니다.

## 수정할 때

- 계산 로직·화면은 `index.html` 하나만 고치면 됩니다.
- 앱 이름·아이콘·화면 모드는 `manifest.webmanifest`에서 변경합니다.
- 파일을 수정해 다시 올릴 때는 `sw.js` 첫 부분의 `var CACHE = "tdc-v1";` 버전을 `tdc-v2`처럼 올려야 이미 설치한 기기에 새 버전이 반영됩니다.

## 저장되는 정보

계산 기록(최대 10개), 마지막으로 본 탭, 밝기 테마는 **각 기기의 브라우저 안에만** 저장됩니다. 서버로 전송되는 정보는 없습니다.

## '알람 앱' 버튼 (아이폰)

시간 계산 탭의 `알람 앱` 버튼은 다음 순서로 시계 앱을 엽니다.

1. `clock-alarm://` 직접 호출 — iOS 버전에 따라 막혀 있을 수 있습니다
2. **단축어 호출** — 아이폰에 아래 단축어를 만들어 두면 확실하게 동작합니다
3. 둘 다 안 되면 안내 문구 표시

### 단축어 만들기 (1회, 약 2분)

1. 아이폰 **단축어** 앱 → 우측 상단 `+`
2. `동작 추가` → 검색창에 **앱 열기** → 선택
3. `앱` 자리를 눌러 **시계** 선택
4. 상단 이름을 **`알람`** 으로 지정 → 완료
   - 시계 앱은 **마지막으로 보던 탭**으로 열립니다. 알람 탭으로 전환해 두고 나오면 이후에는 알람 탭으로 열립니다.
   - `clock-alarm://` 는 현재 iOS에서 탭 지정이 동작하지 않습니다 (시계 앱 실행까지만). 알람 탭을 강제로 여는 공식 방법은 없습니다.

### (선택) 알람을 자동으로 만들기

버튼은 단축어를 호출할 때 **계산 결과 시각**을 `HH:MM` 형태의 입력으로 함께 넘깁니다. 단축어를 아래처럼 바꾸면 시계 앱을 거치지 않고 알람이 바로 생성됩니다.

1. `알람` 단축어 편집 → 기존 **앱 열기** 동작 삭제
2. **텍스트에서 날짜 가져오기** 동작 추가 → 입력에 `단축어 입력` 변수 지정
3. **알람 생성** 동작 추가 → 시간에 위 단계의 날짜 지정, 필요하면 레이블·반복 설정

iOS 버전에 따라 동작 이름이 조금 다를 수 있습니다 (`날짜 가져오기` 등).

단축어 이름을 다르게 하려면 `index.html`에서 `var ALARM_SHORTCUT = "알람";` 의 이름을 바꾸면 됩니다.
